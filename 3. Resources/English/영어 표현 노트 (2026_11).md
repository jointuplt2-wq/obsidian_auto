## 📅 2026-11-01
> 🏷️ **The Lamborghini Is Done!** (람보르기니 완성!) 🏎️🏁

### 💬 오늘의 대화 (Q&A)

| 질문 (Claude) | 답변 (나) |
|---|---|
| Why is Technic easier for you? | Technic-style model kits **are a little** flexible, so I like it. |
| Did you finish the Lamborghini today? | **I finished it at 9:30 AM.** 🎉🏁 |
| Are you happy with it? | Sure, I'm happy. 🏆 |
| Where will you put it? | I'll put it **on top of** the Porsche display case. |
| Is the Porsche also a model kit? | It's also a model kit. 📸 (Gulf 도색!) |
| Were those photos from when you built it? | Yes, they were. 🏆 |
| Why are the wheels off? | If I **put** the wheels **on**, it **rolls on** the desk or **falls off** the desk. |
| Does the Lamborghini have its wheels on? | I put **its** wheels on because **it's in a** different place. 🏆 |
| When will you start the space shuttle? | I will build it **starting** Tuesday. 🚀 |
| Why Tuesday? | **I don't build model kits on Mondays or Thursdays.** 🏆🏆 |

### ✅ 바른 표현 (잘 쓴 문장)
- 🏆🏆 **I don't build model kits on Mondays or Thursdays.**
  → **부정문의 or를 스스로 교정!** 비교해 보세요:
  | 날짜 | 문장 |
  |---|---|
  | 10/27 | I don't build it on Mondays **and** Thursdays. |
  | 11/01 | I don't build model kits on Mondays **or** Thursdays. ✔️ |
  → 9월에 정복한 규칙이 **5주가 지나도 살아 있음**. 복수형(Mondays, model kits)도 정확 👏
- 🏆 **I finished it at 9:30 AM.** — 과거시제 + 대명사 it + 시각 전치사 at, **무오류** ✔️
- 🏆 **Sure, I'm happy.** — 자연스러운 **Sure** + **형용사 앞 be동사** 정확 ✔️
- 🏆 **I put its wheels on ~** — 방금 배운 **put on** + 10/30에 배운 **its**(아포스트로피 ✗) 동시 적용 👏
- 🏆 **Yes, they were.** — 과거·복수 짝 맞추기, **9연속** 성공 ✔️
- 🏆 **If I put the wheels on, ~** — **if 조건문** 구조 안정적 (10/24 첫 등장 이후 정착) 🔑
- 👍 **so I like it** — 결과를 잇는 **so** 사용 ✔️

### 🔄 put on ↔ take off

| 영어 | 뜻 |
|---|---|
| **put** the wheels **on** | 바퀴를 끼우다 |
| **take** the wheels **off** | 바퀴를 빼다 |
| put on / take off a jacket | 입다 / 벗다 |

> ⚠️ **take on**은 "떠맡다" — 전혀 다른 뜻! 📌

### 📍 on vs. off vs. in

| 영어 | 뜻 |
|---|---|
| **on** the desk | 책상 위에 (접촉) |
| **off** the desk | 책상에서 떨어져 |
| fall **off** the desk | 책상에서 떨어지다 ⬇️ |
| **on top of** ~ | ~의 위에 (얹어서) |
| **above** ~ | ~위쪽에 (떨어져서) |
| be **in** a different place | 다른 곳에 있다 |

## 📝 문법 팁 모음

- **at** + 시각 (at 12:30) / **in** + 기간 (in the morning) / **at** night 🌙
- 목록 마지막엔 **and**: "A, B, **and** C" (and etc. ✗ → **and so on**)
- 습관은 현재형: "I **study** English every day"
- 원인/결과: **because of** + 명사 / **because** + 문장 / 결과는 **so**
- 질문의 동사 = 대답의 동사: **Are** you ~? → Yes, I **am**. ⭐
- 조동사(will/did/can) 뒤에는 **반드시 동사원형** 🔑
- 형용사는 혼자 설 수 없다 → 앞에 **be동사** 필수 ("The parts **are** easier")
- 비교급 3종 세트: **be동사** + **‑er/more** + **than**
- **It's easier for me** (I'm easier ✗) — 쉬운 건 '그 작업' 👤
- **the same as** ~ / similar **to** ~ / different **from** ~
- 최상급엔 **the** (the best) / 비교급엔 **the** 없음 (better than)
- **it** 뒤에는 **has** (3인칭 단수) 🔄
- **by** = 완료 시점 / **until** = 지속 ⏰
- every + **단수** (every week) — 숫자가 끼면 복수 (every two days)
- 형용사가 붙어도 관사는 필요: **a** very complicated kit
- **one of the** + 복수 → 동사는 **단수**
