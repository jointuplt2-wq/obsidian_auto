### 🔄 put on ↔ take off

| 영어 | 뜻 |
|---|---|
| **put** the wheels **on** | 바퀴를 끼우다 |
| **take** the wheels **off** | 바퀴를 빼다 |
| put on / take off a jacket | 입다 / 벗다 |

> ⚠️ **take on**은 "떠맡다" — 전혀 다른 뜻! 📌

### 📍 on vs. off vs. in

| 영어 | 뜻 |
|---|---|
| **on** the desk | 책상 위에 (접촉) |
| **off** the desk | 책상에서 떨어져 |
| fall **off** the desk | 책상에서 떨어지다 ⬇️ |
| **on top of** ~ | ~의 위에 (얹어서) |
| **above** ~ | ~위쪽에 (떨어져서) |
| be **in** a different place | 다른 곳에 있다 |

| My friends **just will** display | My friends **will just** display | 🔄 부사는 조동사 **뒤** |
| I told you that I **will have to** | I told you that I **had to** | 🚨 **시제 일치** |

### 🔑 시제 일치 (주절이 과거면 that절도 과거)

| 직접 말 | 전달할 때 |
|---|---|
| "I **will** go." | I said I **would** go. |
| "I **have to** work." | I told you I **had to** work. ✔️ |
| "It **is** hard." | I said it **was** hard. |

> 🔁 11/15에 배운 **would**가 여기서도 쓰인다 🔑

### 🔑 부사(just/only) 위치

| 동사 종류 | 위치 | 예문 |
|---|---|---|
| **조동사** (will/can) | 조동사 **뒤** | will **just** display ✔️ |
| **일반동사** | 동사 **앞** | **just** listen ✔️ 🔁 |
| **be동사** | be동사 **뒤** | is **just** fine |

### 🔑 by vs. with (복습)

| 영어 | 뜻 |
|---|---|
| sort them **by size / by color** | 기준·방법 ✔️ |
| wash it **with** bleach | 도구·재료 🔁 (11/14) |

### 🗂️ 정리·분류 어휘

| 영어 | 뜻 |
|---|---|
| **sort** them by size | 크기별로 분류하다 ✔️ |
| make **two piles** | 두 무더기로 나누다 |
| **keep** vs **give away** | 남길 것 vs 줄 것 |
| I **threw away** a lot. | 많이 버렸어요 |
| It looks **much better** now. | 훨씬 나아 보여요 ✨ |

### 🎁 물려주기 표현

| 영어 | 뜻 |
|---|---|
| give them **to** my friends | 친구들에게 주다 ✔️ |
| someone who'll **appreciate** it | 고마워할 사람 ✨ |
| **Not a single one.** | 하나도 안 남겨요 |
| **A clean slate.** | 백지 상태로 🔑 |
| I'm starting **fresh**. | 새로 시작해요 |

### 🆕 "~에게 처음이다"

| 영어 | 뜻 |
|---|---|
| It's **new to/for** them. | 그들에겐 처음이에요 ✔️ |
| They've **never tried** it. | 해본 적 없어요 |
| They're **beginners**. | 초보자예요 |
| They're **curious** about it. | 궁금해해요 |

### 📦 이사 준비 현황

| 항목 | 내용 |
|---|---|
| 오늘 오전 | **방 청소 완료** 🧹 |
| 모델 키트 | **크기별로 분류 완료** (대3 · 중3 · 소5) |
| 처분 방식 | **친구들에게 전부** — 조립 없이 **전시용**으로 |
| 본인 보관 | **없음** (하나도 안 남김) |
| 주말 | 방 정리 집중 → **SUV 조립은 다음 주** 🚙 |

### 💡 오늘의 팁
> **"I will give them to my friends."** 가 오늘의 백미였습니다. 11/17에 "distribute to center persons"로 고쳐드렸던 바로 그 구조를, 오늘은 **처음부터 정확히** 쓰셨어요. 나흘 만의 변화입니다. 👏
> 🎯 교정 핵심은 **시제 일치** — "I told you that I **had to** ~" 주절이 과거면 that절도 과거로 맞춥니다. 📌
> 🧹 방 정리도 끝내시고 키트 분류까지. 하나도 안 남기고 친구들에게 주신다니, 정말 **a clean slate**네요. ✨

## 📝 문법 팁 모음

- **at** + 시각 (at 12:30) / **in** + 기간 (in the morning) / **at** night 🌙
- 목록 마지막엔 **and**: "A, B, **and** C" (and etc. ✗ → **and so on**)
- 습관은 현재형: "I **study** English every day"
- 원인/결과: **because of** + 명사 / **because** + 문장 / 결과는 **so**
- 질문의 동사 = 대답의 동사: **Are** you ~? → Yes, I **am**. ⭐
- 조동사(will/did/can) 뒤에는 **반드시 동사원형** 🔑
- 형용사는 혼자 설 수 없다 → 앞에 **be동사** 필수 ("The parts **are** easier")
- 비교급 3종 세트: **be동사** + **‑er/more** + **than**
- **It's easier for me** (I'm easier ✗) — 쉬운 건 '그 작업' 👤
- **the same as** ~ / similar **to** ~ / different **from** ~
- 최상급엔 **the** (the best) / 비교급엔 **the** 없음 (better than)
- **it** 뒤에는 **has** (3인칭 단수) 🔄
- **by** = 완료 시점 / **until** = 지속 ⏰
- every + **단수** (every week) — 숫자가 끼면 복수 (every two days)
- 형용사가 붙어도 관사는 필요: **a** very complicated kit
- **one of the** + 복수 → 동사는 **단수**
