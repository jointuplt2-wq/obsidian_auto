## 📅 2026-08-01
> 🏷️ **Bean Paste Soup & Memories of Busan** (된장국과 부산의 추억)

### 💬 오늘의 대화 (Q&A)

| 🤖 너의 질문 | 🙋 나의 대답 |
|---|---|
| How is your day going so far? | It's going well. |
| Did you have a nice breakfast? | Yes, I did. |
| What did you have for breakfast? | I had rice and soup for breakfast. |
| What kind of soup was it? | It was bean paste soup. |
| Is it one of your favorites? | Yes, it's one of my favorites. |
| What do you put in it? | It had napa cabbage in it this morning. |
| What other vegetables do you like in soup? | I like tofu and potatoes in my soup. |
| Do you cook it yourself, or the dining hall? | The dining hall always makes it. |
| Would you like to learn to cook? | I prefer having meals prepared for me. |
| Any food you wish they made more often? | I wish they made fried chicken more often. |
| How often do they serve it now? | They serve it about twice a month. |
| Do you have special plans for August? | No, I don't have any special plans. |
| Anything you'd like to do this summer? | I want to go to Busan. |
| Have you been there before? | I'm from Busan. |
| Do family or friends still live there? | Yes, my family and friends live in Busan. |
| When did you last visit? | I visited Busan about fifteen years ago. |
| What do you remember most? | The beaches and the fresh seafood. |
| Which beach? | It was Haeundae Beach. |

### ✅ 바른 표현 (잘 쓴 문장)
- **It's one of my favorites.** ⭐
- **The dining hall always makes it.** (단수 → makes) 🍲
- **I prefer having meals prepared for me.** (동명사 + 수동태, 훌륭!) 🌟
- **I wish they made fried chicken more often.** (가정법!) 🍗
- **It was Haeundae Beach.** 🏖️

### ❌ 틀린 단어와 수정본 (Corrections)
| ❌ 내가 쓴 표현 | ✅ 바른 표현 |
|---|---|
| It had put napa cabbage in **today morning** | It had napa cabbage in it **this morning** ☀️ |
| I like tofu and **potato** | I like tofu and **potatoes** (일반적 복수) 🥔 |
| I don't have **special** plans | I don't have **any** special plans (부정문 any) 🚫 |
| **PUSAN** | **Busan** (현대 표기 + 대문자만 첫 글자) 🏙️ |
| **i'm** from Busan | **I'm** from Busan (I는 항상 대문자) ✍️ |
| my family and friends **lives** | my family and friends **live** (복수 주어) 👥 |
| I **did visit** Busan | I **visited** Busan (평서문은 그냥 과거형) 🚄 |

### 🔤 헷갈리는 단어·표현
| 표현 | 뜻 |
|---|---|
| bean paste soup | 된장국 🥘 |
| napa cabbage | 배추 🥬 |
| this morning (O) / today morning (X) | 오늘 아침 ☀️ |
| tofu / potatoes | 두부 / 감자(복수) 🥔 |
| any (부정문) vs some (긍정문) | ~도 없다 / 조금 있다 |
| Busan | 부산 (현대 로마자 표기) 🏙️ |
| Haeundae Beach | 해운대 해수욕장 🏖️ |
| seafood | 해산물 🦐 |
| I wish + 과거동사 | ~라면 좋을 텐데 (가정법) 🙏 |

### 💡 오늘의 팁
- **this morning** 이라고 함 (today morning ✗) ☀️
- 부정문엔 **any**: I don't have **any** plans 🚫
- 주어가 복수면 동사에 -s 안 붙임: friends **live** 👥
- **I wish + 과거동사** = ~라면 좋을 텐데 (가정법): I wish they **made** it 🙏
- **did + 동사원형** = 강조일 때만, 평소엔 그냥 과거형: I **visited** (O) 💯
- **prefer + -ing**: I prefer **having** meals prepared 🍽️

- **Yes, I have learned a lot from them.** (현재완료) 💯

### ❌ 틀린 단어와 수정본 (Corrections)
| ❌ 내가 쓴 표현 | ✅ 바른 표현 |
|---|---|
| (How are you?) **Nothing** | **I'm good, thanks** (기분을 답함) 😊 |
| I **aet** a cookie | I **ate** a cookie (eat → ate) 🍪 |
| a **cookies** | a **cookie** (하나) / cookies (여러 개) |
| **th6e** Oreo | **an** Oreo (음식 이름엔 the 안 씀) 🍪 |
| English **Grammer** | English **grammar** (-ar로 끝남) ✍️ |

### 🔤 헷갈리는 단어·표현
| 표현 | 뜻 |
|---|---|
| How are you doing? | 기분·상태를 물음 (→ I'm good) 😊 |
| What are you doing? | 활동을 물음 (→ Nothing much) 🛋️ |
| eat → ate → eaten | 먹다 (불규칙 동사) 🍪 |
| fabulous | 아주 멋진, 훌륭한 ✨ |
| an Oreo / Oreos | 오레오 (한 개 / 여러 개) 🍪 |
| dip in ~ | ~에 담그다, 찍어 먹다 🥤 |
| fizzy | 톡 쏘는, 탄산의 🫧 |
| OJ | orange juice의 줄임말 🍊 |
| grammar | 문법 (철자 -ar!) 📖 |
| I have learned ~ | ~을 배워왔다 (현재완료) 💯 |

### 💡 오늘의 팁
- **How are you doing?** → 기분 답변 (I'm good) / **What are you doing?** → 활동 답변 (Nothing) 🔄
- **eat**의 과거 = **ate** (불규칙 동사) 🍪
- 음식 이름엔 **the** 안 씀: **an** Oreo, **an** apple 🍎
- **grammar** 철자: **-ar**로 끝남 (grammer ✗) ✍️
- 현재완료 **have + p.p.** = 과거부터 지금까지: I **have learned** 💯

### ❌ 틀린 단어와 수정본 (Corrections)
| ❌ 내가 쓴 표현 | ✅ 바른 표현 |
|---|---|
| I watched about **Japan languag YouTube** | I watched **a YouTube video about the Japanese language** 🎥 |
| Japanese **language** (반복) | just **Japanese** (Japanese = 이미 '일본어') 🗣️ |
| I watch **animation OTT** | I watch **anime on streaming services** 📺 |
| **Almost** animation is Japanese | **Most** anime is Japanese (most + 명사) 🇯🇵 |

### 🔤 헷갈리는 단어·표현
| 표현 | 뜻 |
|---|---|
| Japan vs Japanese | 일본(나라) 🇯🇵 vs 일본어·일본인 🗣️ |
| language | 언어 (철자 -uage) ✍️ |
| watch a video on YouTube | 유튜브에서 영상을 보다 🎬 |
| anime | 일본 애니메이션 🎌 |
| most (+ 명사) vs almost (+ all) | 대부분의 vs 거의 모든 |
| streaming service / OTT | 스트리밍 서비스 📱 |
| action scene | 액션 장면 🔥 |
| konnichiwa (こんにちは) | 안녕하세요 (일본어 인사) 🇯🇵 |

### 💡 오늘의 팁
- 나라는 **Japan**, 언어·사람은 **Japanese** 🇯🇵
- **Japanese** 자체가 '일본어' → *Japanese language*는 중복 (그냥 Japanese)
- **watch a video on YouTube** (YouTube**에서** 영상을 보다) 🎬
- **most + 명사** (대부분의) / **almost + all** (거의 모든): **Most** anime / **Almost all** anime
- **anime** = 일본 애니메이션 (영어권에서도 이 단어를 씀) 🎌

- **a little while ago** = 조금 전에 ⏰
- 이미 끝난 일엔 **과거형 got** (get ✗) ✂️

- **The building and the food have changed a lot.**

### ❌ 틀린 단어와 수정본 (Corrections)

| 내가 쓴 표현 | 바른 표현 | 설명 |
|---|---|---|
| Care worker assist when I had a shower | **A care worker assisted me** when I had a shower | 관사 **a** + 과거형 **assisted** |
| care workr | **care worker** | 철자 |
| Here lives about seventy people | **About seventy people live here** | 어순: 주어(seventy people) 먼저 |
| I lived here about fifteen years ago | **I have lived here for about fifteen years** | 지금도 살고 있음 → 현재완료 |
| They work here one day every 3 days | **one day out of every three** | 자연스러운 표현 |
| The food improved since... | **The food has improved** since... | since + 현재완료 |
| diniing | **dining** | 철자 |

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| assist = help | 돕다 (assist**ed** 과거) 🤝 |
| care worker | 요양보호사 💙 |
| out of every three | 셋 중 하나 (비율) |
| put out to bid | 입찰에 부치다 📋 |
| contract out | 외주를 주다 |
| has improved | 좋아졌다 (현재완료) 📈 |

### 💡 오늘의 팁
- **과거의 일** = 과거형: care worker **assisted** me (assist ✗) 🤝
- **어순**: 주어 + 동사 → "About seventy people **live** here" (Here live... ✗)
- **지금도 계속됨** = 현재완료: "I **have lived** here for 15 years" 🏠
- **since**(~이래로) + **has/have + p.p.**: "The food **has improved** since..." 📈

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| **delicate** | 섬세한, 깨지기 쉬운 |
| **be careful** | 조심하다 (사람 주어!) 🤲 |
| **longer than I thought** | 생각보다 오래 걸린 ⏱️ |
| **harder than I thought** | 생각보다 어려운 |
| **easier than I thought** | 생각보다 쉬운 |
| **glue ~ back together** | 다시 붙이다 🩹 |
| **head frame** | 앞부분 뼈대 |
| **probably / should + 동사** | 아마 ~할 것이다 |

### 💡 오늘의 팁
- **careful은 사람에게만!** 물건은 **delicate** 🤲
- **~than I thought** = 생각보다 ~한 (longer / harder / easier) ⏱️
- **it**(하나) vs **them**(여러 개) — some parts → them ✌️
- 지금 하는 중 → **am/is/are + -ing** ⏳
- ⚠️ **반복 실수 3번째!** about + 시점(tomorrow) ✗ → **should/probably** 사용 🚨
- 오늘 복습 성공! **delicate**, **them**, **work on it**, **it hasn't arrived yet** 🎉

|---|---|

| **model kit** | 조립 모형 세트 🧩 |
| **plastic model kit** | 프라모델 |
| **wooden model kit** | 원목 조립 키트 |
| **a vs. the** | 아무거나 하나 / 서로 아는 그것 |

### 🔢 One / Another / The other (핵심 정리!)

| 개수 | 표현 |
|---|---|
| **2개** | One is A, **the other** is B. ✌️ |
| **3개** | One is A, **another** is B, **the other** is C. 🔢 |

### 💡 오늘의 팁
- **yet**은 **현재완료(has/have + p.p.)**와 짝꿍 🤝 — hasn't arrived yet ✔️
- **give up on** + 명사/동명사 🏳️
- ⚠️ **반복 실수!** another vs the other — **2개면 the other** ✌️ (월요일에도 틀림)
- 🚨 **a/an 오늘 4번 놓침!** 셀 수 있는 명사 하나엔 항상 **a/an** 🅰️
- **material**(재료) ≠ **kit**(조립 세트) 🧩
- 오늘 복습 성공! **going through customs**, **delicate** 🎉
