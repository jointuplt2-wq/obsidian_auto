## 📅 2026-09-01
> 🏷️ **Fighter Jets & a Tiny Dachshund** (전투기들과 작은 닥스훈트)

### 💬 오늘의 대화 (Q&A)

| 질문 (Claude) | 답변 (나) |
|---|---|
| Did you build the arms? | No, I built new model kits. |
| How many kits did you build today? | I built two model kits yesterday and this morning. |
| Were they easier than the panda? | Yes, they were much easier. |
| How many pieces did each one have? | Each one has twenty-five pieces. |
| Which one do you like more — the F-14 or the SU-57? | I like the F-14 more. |
| Why do you like it more? | Because it looks cooler. The Tomcat appeared in the movie Top Gun. |
| Did you watch Top Gun? | Yes, I watched it a long time ago. |
| Did you like the movie? | Yes, I liked it very much. |
| What will you build next? | I will build a small dachshund. |
| Is it also a small kit? | Yes, it's a small kit. |
| Is it a mini block kit? | Yes, it is a mini block kit. |
| When will you start? | I will start this afternoon. |

### ✅ 바른 표현 (잘 쓴 문장)
- **No, I built new model kits.** ✈️
- **I built two model kits yesterday and this morning.** 🔨
- **Yes, they were much easier.** — much + 비교급! 📊
- **I like the F-14 more.** ✈️
- **Because it looks cooler.** — look + 비교급 정확! 😎
- **Yes, I watched it a long time ago.** ⏳
- **Yes, I liked it very much.** — very much 어순 정확! 👍
- **I will build a small dachshund.** — a 정확! 🐕
- **Yes, it's a small kit. / Yes, it is a mini block kit.** 🧱
- **I will start this afternoon.** — 전치사 없음 정확! 🎯

### ❌ 틀린 단어와 수정본 (Corrections)

| 내가 쓴 표현 | 바른 표현 | 설명 |
|---|---|---|
| They have twenty five pieces **each one** | **Each one has** twenty-**five** pieces | each one은 문장 앞! / 21-99는 하이픈 |
| Tomcat **was appeared** in movie, TopGun | **The** Tomcat **appeared** in **the** movie **Top Gun** | appear는 수동태 ✗ / 관사 / 영화 제목 두 단어 |

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| **much + 비교급** | 훨씬 더 ~한 (much easier, much bigger) 📊 |
| **look + 비교급** | 더 ~해 보이다 (looks cooler) 😎 |
| **each one has ~** | 각각 ~을 가지고 있다 |
| **a long time ago** | 오래 전에 ⏳ |
| **not long ago** | 얼마 전에 |
| **very much** | 아주 많이 (문장 끝) |
| **dachshund** | 닥스훈트 🐕 (발음: 닥순드) |
| **mini block kit** | 미니 블록 조립 세트 🔬🧱 |
| **fighter (jet)** | 전투기 ✈️ |

### 🚨 수동태로 쓰지 않는 동사들

| 틀림 ❌ | 맞음 ✅ |
|---|---|
| was **appeared** | **appeared** |
| was **happened** | **happened** |
| was **arrived** | **arrived** |
| was **occurred** | **occurred** |

> 💡 스스로 일어나는 동작은 수동태를 쓰지 않아요!

### 🔢 숫자 하이픈 규칙

| 숫자 | 영어 |
|---|---|
| 25 | twenty-**five** |
| 31 | thirty-**one** |
| 42 | forty-**two** |
| 100 | one hundred (하이픈 ✗) |

> 💡 **21~99**만 하이픈으로 연결! ➖

### 💡 오늘의 팁
- **much + 비교급** = 훨씬 더 ~한 📊
- **each one**은 문장 **맨 앞**에! (문장 끝 ✗) 📌
- **21-99는 하이픈**: twenty-five ➖
- 🚨 **appear / happen / arrive는 수동태 ✗** — 능동태로만! ⚠️
- 영화 제목엔 **the movie** + 제목 🎬
- 오늘 12문장 중 10문장 완벽! 🏆

## 📅 2026-09-02
> 🏷️ **Tiny Blocks & a Metal Motorcycle** (작은 블록과 금속 오토바이)

### 💬 오늘의 대화 (Q&A)

| 질문 (Claude) | 답변 (나) |
|---|---|
| Did you build the dachshund? | Yes, but the pieces kept falling off one after another. |
| Because the mini blocks are too small? | Yes, they are too small. I'm building another model kit. |
| Is this a metal kit? | Yes, it is a metal kit. |
| Do you need a screwdriver? | Yes, I need an electric screwdriver. |
| Do you have one? | Yes, I have one. |
| Is the metal kit easier than the mini blocks? | No, it's the same. |
| Are the screws tiny too? | Yes, it is hard too. Yes, they are tiny. |
| Will you finish the motorcycle today? | I'll finish it in three days. |

### ✅ 바른 표현 (잘 쓴 문장)
- **Yes, they are too small.** 🔬
- **Yes, it is a metal kit.** 🔩
- **Yes, I have one.** — one으로 명사 대신! 🎯
- **Yes, it is hard too.** / **Yes, they are tiny.** — it(하나)/they(여러 개) 구분 정확! 👏
- **another** model kit — 3개 이상 중 또 하나, 정확! ✔️

### ❌ 틀린 단어와 수정본 (Corrections)

| 내가 쓴 표현 | 바른 표현 | 설명 |
|---|---|---|
| delaied | **delayed** | 철자 |
| It came out one piece **the another** piece | The pieces kept **falling off one after another** | one after another = 하나씩 차례로 |
| I **has building** another model kit ⚠️반복 | I'**m building** another model kit | 8/23에도 틀림! 현재진행형 |
| **a** eletric-screwdriver | **an electric screwdriver** | 모음 앞 an / 철자 / 하이픈 ✗ |
| it's **same** ⚠️반복 | it's **the same** | 8/29에도 틀림! same 앞엔 the |
| aftder **threedays** | **in three days** | 철자 / 두 단어 / 미래엔 in |

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| **one after another** | 하나씩 차례로 |
| **come off / fall off** | 떨어져 나오다 🔩 |
| **come out** | (밖으로) 나오다 📤 |
| **keep + -ing** | 계속 ~하다 |
| **screw** | 나사 🔩 |
| **nut** | 너트 |
| **screwdriver** | 드라이버 🪛 |
| **electric screwdriver** | 전동 드라이버 ⚡ |
| **metal kit** | 금속 조립 세트 |
| **three-wheeled motorcycle** | 삼륜 오토바이 🏍️ |

### 🅰️ a vs. an (모음 소리 규칙)

| a (자음 소리) | an (모음 소리) |
|---|---|
| **a** metal kit | **an** electric screwdriver ⚡ |
| **a** dachshund 🐕 | **an** apple 🍎 |
| **a** university (유~) | **an** hour (아워~) ⏰ |

> 💡 **글자가 아니라 소리로 판단!** hour는 h 발음이 없어서 **an** ⏰

### ⏳ in vs. after (시간)

| 표현 | 뜻 |
|---|---|
| **in** three days | 3일 **후에** (미래) ✔️ |
| **in** an hour | 한 시간 후에 |
| **after** lunch | 점심 먹은 **후에** (특정 사건 뒤) |

> 💡 미래의 "~후에"는 **in**! (after ✗) 🎯

### 💡 오늘의 팁
- **one after another** = 하나씩 차례로 🔁
- **come off**(떨어져 나오다) ≠ **come out**(밖으로 나오다) 🔩
- 🅰️ **모음 소리 앞엔 an**: an electric, an hour, an apple
- ⏳ **미래의 "~후에"는 in**: in three days ✔️ / after three days ✗
- ⚠️ **반복 실수 2개!**
  - **I has building** → I'**m** building (8/23에도 틀림) ⏳
  - **it's same** → it's **the** same (8/29에도 틀림) 🔑
- 잘한 점: **another** 정확, **it/they** 구분 정확! 👏

## 📝 문법 팁 모음

- **at** + 시각 (at 12:30) / **in** + 기간 (in the morning)
- 목록 마지막엔 **and**: "A, B, **and** C"
- 습관은 현재형: "I **study** English every day" (will 안 씀)
- 원인/결과: **because of** + 명사 / **because** + 문장 / 결과는 **so**
- **ask + 사람 + to + 동사**: "ask you to teach me"
- 장소: **"I'm in [도시]"** (Here is [도시] ✗)
