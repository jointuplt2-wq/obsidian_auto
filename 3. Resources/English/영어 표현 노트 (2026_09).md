### 💬 오늘의 대화 (Q&A)

| 질문 (Claude) | 답변 (나) |
|---|---|
| Did you build the arms? | No, I built new model kits. |

| Were they easier than the panda? | Yes, they were much easier. |

| Did you watch Top Gun? | Yes, I watched it a long time ago. |

| What will you build next? | I will build a small dachshund. |

| Is it a mini block kit? | Yes, it is a mini block kit. |
| When will you start? | I will start this afternoon. |

### ✅ 바른 표현 (잘 쓴 문장)
- **No, I built new model kits.** ✈️
- **I built two model kits yesterday and this morning.** 🔨
- **Yes, they were much easier.** — much + 비교급! 📊
- **I like the F-14 more.** ✈️
- **Because it looks cooler.** — look + 비교급 정확! 😎
- **Yes, I watched it a long time ago.** ⏳
- **Yes, I liked it very much.** — very much 어순 정확! 👍
- **I will build a small dachshund.** — a 정확! 🐕
- **Yes, it's a small kit. / Yes, it is a mini block kit.** 🧱
- **I will start this afternoon.** — 전치사 없음 정확! 🎯

### ❌ 틀린 단어와 수정본 (Corrections)

| 내가 쓴 표현 | 바른 표현 | 설명 |
|---|---|---|
| They have twenty five pieces **each one** | **Each one has** twenty-**five** pieces | each one은 문장 앞! / 21-99는 하이픈 |
| Tomcat **was appeared** in movie, TopGun | **The** Tomcat **appeared** in **the** movie **Top Gun** | appear는 수동태 ✗ / 관사 / 영화 제목 두 단어 |

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| **much + 비교급** | 훨씬 더 ~한 (much easier, much bigger) 📊 |
| **look + 비교급** | 더 ~해 보이다 (looks cooler) 😎 |
| **each one has ~** | 각각 ~을 가지고 있다 |
| **a long time ago** | 오래 전에 ⏳ |
| **not long ago** | 얼마 전에 |
| **very much** | 아주 많이 (문장 끝) |
| **dachshund** | 닥스훈트 🐕 (발음: 닥순드) |
| **mini block kit** | 미니 블록 조립 세트 🔬🧱 |
| **fighter (jet)** | 전투기 ✈️ |

### 🚨 수동태로 쓰지 않는 동사들

| 틀림 ❌ | 맞음 ✅ |
|---|---|
| was **appeared** | **appeared** |
| was **happened** | **happened** |
| was **arrived** | **arrived** |
| was **occurred** | **occurred** |

> 💡 스스로 일어나는 동작은 수동태를 쓰지 않아요!

### 🔢 숫자 하이픈 규칙

| 숫자 | 영어 |
|---|---|
| 25 | twenty-**five** |
| 31 | thirty-**one** |
| 42 | forty-**two** |
| 100 | one hundred (하이픈 ✗) |

> 💡 **21~99**만 하이픈으로 연결! ➖

### 💡 오늘의 팁
- **much + 비교급** = 훨씬 더 ~한 📊
- **each one**은 문장 **맨 앞**에! (문장 끝 ✗) 📌
- **21-99는 하이픈**: twenty-five ➖
- 🚨 **appear / happen / arrive는 수동태 ✗** — 능동태로만! ⚠️
- 영화 제목엔 **the movie** + 제목 🎬
- 오늘 12문장 중 10문장 완벽! 🏆

| 질문 (Claude) | 답변 (나) |
|---|---|
| Did you build the dachshund? | Yes, but the pieces kept falling off one after another. |
| Because the mini blocks are too small? | Yes, they are too small. I'm building another model kit. |
| Is this a metal kit? | Yes, it is a metal kit. |
| Do you need a screwdriver? | Yes, I need an electric screwdriver. |
| Do you have one? | Yes, I have one. |
| Is the metal kit easier than the mini blocks? | No, it's the same. |
| Are the screws tiny too? | Yes, it is hard too. Yes, they are tiny. |
| Will you finish the motorcycle today? | I'll finish it in three days. |

### ✅ 바른 표현 (잘 쓴 문장)
- **Yes, they are too small.** 🔬
- **Yes, it is a metal kit.** 🔩
- **Yes, I have one.** — one으로 명사 대신! 🎯
- **Yes, it is hard too.** / **Yes, they are tiny.** — it(하나)/they(여러 개) 구분 정확! 👏
- **another** model kit — 3개 이상 중 또 하나, 정확! ✔️

### ❌ 틀린 단어와 수정본 (Corrections)

| 내가 쓴 표현 | 바른 표현 | 설명 |
|---|---|---|
| delaied | **delayed** | 철자 |
| It came out one piece **the another** piece | The pieces kept **falling off one after another** | one after another = 하나씩 차례로 |
| I **has building** another model kit ⚠️반복 | I'**m building** another model kit | 8/23에도 틀림! 현재진행형 |
| **a** eletric-screwdriver | **an electric screwdriver** | 모음 앞 an / 철자 / 하이픈 ✗ |
| it's **same** ⚠️반복 | it's **the same** | 8/29에도 틀림! same 앞엔 the |
| aftder **threedays** | **in three days** | 철자 / 두 단어 / 미래엔 in |

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| **one after another** | 하나씩 차례로 |
| **come off / fall off** | 떨어져 나오다 🔩 |
| **come out** | (밖으로) 나오다 📤 |
| **keep + -ing** | 계속 ~하다 |
| **screw** | 나사 🔩 |
| **nut** | 너트 |
| **screwdriver** | 드라이버 🪛 |
| **electric screwdriver** | 전동 드라이버 ⚡ |
| **metal kit** | 금속 조립 세트 |
| **three-wheeled motorcycle** | 삼륜 오토바이 🏍️ |

### 🅰️ a vs. an (모음 소리 규칙)

| a (자음 소리) | an (모음 소리) |
|---|---|
| **a** metal kit | **an** electric screwdriver ⚡ |
| **a** dachshund 🐕 | **an** apple 🍎 |
| **a** university (유~) | **an** hour (아워~) ⏰ |

> 💡 **글자가 아니라 소리로 판단!** hour는 h 발음이 없어서 **an** ⏰

### ⏳ in vs. after (시간)

| 표현 | 뜻 |
|---|---|
| **in** three days | 3일 **후에** (미래) ✔️ |
| **in** an hour | 한 시간 후에 |
| **after** lunch | 점심 먹은 **후에** (특정 사건 뒤) |

> 💡 미래의 "~후에"는 **in**! (after ✗) 🎯

### 💡 오늘의 팁
- **one after another** = 하나씩 차례로 🔁
- **come off**(떨어져 나오다) ≠ **come out**(밖으로 나오다) 🔩
- 🅰️ **모음 소리 앞엔 an**: an electric, an hour, an apple
- ⏳ **미래의 "~후에"는 in**: in three days ✔️ / after three days ✗
- ⚠️ **반복 실수 2개!**
  - **I has building** → I'**m** building (8/23에도 틀림) ⏳
  - **it's same** → it's **the** same (8/29에도 틀림) 🔑
- 잘한 점: **another** 정확, **it/they** 구분 정확! 👏

## 📅 2026-09-03
> 🏷️ **Bolts, Nuts & Tweezers** (볼트, 너트, 그리고 핀셋) 📚

### 🎯 오늘의 복습 퀴즈 (5/6 정답!) 🥇
> 📚 **두 번째 강제 복습날** — 반복 실수 3개를 전부 한 번에 정답! 🔥

| 틀린 문장 | 내 답 | 정답 |
|---|---|---|
| I **has building** another model kit. ⚠️8/23 반복 | "has >> am" ✔️ | I'**m building** another model kit. |
| No, it's **same**. ⚠️8/29 반복 | "same >> the same" ✔️ | No, it'**s the same**. |
| I need **a eletric-screwdriver**. | "an eletric screwdriver" (철자 ✗) → 2차 정답 ✔️ | I need **an electric screwdriver**. |
| I'll finish it **after threedays**. | "in three days" ✔️✔️ | I'll finish it **in three days**. |
| It came out one piece **the another** piece. | "one after another" ✔️ | The pieces kept falling off **one after another**. |
| It will arrive **about** tomorrow. ⚠️반복 | "about tomorrow는 틀렸어" ✔️ | It **should** arrive tomorrow. |

**복습 총평:** 6문제 중 5개를 한 번에 정답! 반복 실수 3개(I'm building / the same / about + 시점)를 **전부 정복**! 🏆

---

### 💬 오늘의 대화 (Q&A)

| 질문 (Claude) | 답변 (나) |
|---|---|
| How is the metal motorcycle going? | It's very hard to build because of the bolts and nuts. |
| Are the bolts hard to turn? | No, they aren't hard to turn. I have the electric screwdriver. |
| So what's the hard part then? | The small nuts are hard to hold and assemble. |
| Do you use tweezers? | Yes, I use tweezers. |
| How much have you finished so far? | I finished assembling five bolts and nuts. |
| How many bolts are there in total? | There are about thirty bolts. |
| Will you finish it in three days? | I think I will finish it in seven days. |

### ✅ 바른 표현 (잘 쓴 문장)
- **because of** the bolts and nuts — 문법 팁의 규칙 정확 적용! 📝
- **No, they aren't hard to turn.** — hard to + 동사 패턴 습득! 👏
- **The small nuts are hard to hold** — 같은 패턴 반복 사용! 🎯
- **Yes, I use tweezers.** 🤏
- **There are about thirty bolts.** — There are + about + 숫자 정확! 🔢
- **in seven days** — 오늘 아침 복습한 걸 바로 사용! 🔥

### ❌ 틀린 단어와 수정본 (Corrections)

| 내가 쓴 표현 | 바른 표현 | 설명 |
|---|---|---|
| **It build** very hard | It'**s very hard to build** | it은 스스로 만들 수 없음 |
| because of bolts, nuts | because of **the** bolts **and** nuts | 관사 / 목록 마지막엔 and |
| e**i**ectric ⚠️2회 | e**l**ectric | 두 번째 글자는 L! |
| hard to hold and **asembly** | hard to hold and **assemble** | assembly(명사) ≠ assemble(동사) / ss |
| I finished **the five bolts and nuts assemble** | I finished **assembling five bolts and nuts** | finish + -ing / the 빼기 / 어순 |
| I will finish in seven days | I will finish **it** in seven days | finish는 목적어 필요 |

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| **bolt** | 볼트 🔩 |
| **nut** | 너트 |
| **screw** | 나사 |
| **tweezers** | 핀셋 🤏 (항상 -s!) |
| **assemble** (동사) | 조립하다 ✔️ |
| **assembly** (명사) | 조립(품) |
| **hard to + 동사** | ~하기 어렵다 |
| **finish + -ing** | ~하기를 끝내다 |
| **in total** | 전부 합쳐서 |

### 🤏 항상 복수형인 단어들

| 단어 | 뜻 |
|---|---|
| **tweezers** | 핀셋 🤏 |
| **scissors** | 가위 ✂️ |
| **glasses** | 안경 👓 |
| **pants / jeans** | 바지 👖 |

> 💡 두 짝으로 된 물건은 항상 **-s**! **They are** tweezers ✔️

### 🎯 finish + -ing (동명사)

| 맞음 ✅ | 틀림 ❌ |
|---|---|
| finish **building** | finish to build |
| finish **eating** | finish to eat |
| finish **assembling** | finish assemble |

### 💡 오늘의 팁
- **hard to + 동사** = ~하기 어렵다 (hard to build / hold / turn) 🎯
- **finish + -ing** — to부정사 ✗ ⚠️
- **assemble**(동사) ≠ **assembly**(명사) 🔧
- **tweezers, scissors, glasses**는 항상 복수! 🤏
- ⚡ **electric** 철자 오늘 2번 틀림 — 단어장에 5번 쓰기! ✍️
- 🏆 반복 실수 3개를 복습에서 전부 정복! (I'm building / the same / about + 시점) 🔥
- **in seven days** — 아침에 배운 걸 대화에서 바로 사용! 👏

### ❌ 틀린 단어와 수정본 (Corrections)

| 내가 쓴 표현 | 바른 표현 | 설명 |
|---|---|---|
| I **didn't finish** it yet ⚠️반복 | I **haven't finished** it yet | 8/26에도 틀림! yet + 현재완료 |
| eaesier | **easier** | 철자 (e-a-s-i-e-r) |
| I **decided building** ~ **more than** an easier kit | I **decided to build** easier kits **instead of** the motorcycle | decide + to부정사 / instead of |
| I finished four kits and **remained one kit** | I finished four kits, and **one is left** | remain은 자동사 |
| It's SU-27 | It's **an** SU-27 | S=에스(모음 소리) → an |

### 🔤 헷갈리는 단어·표현

| 표현 | 뜻 |
|---|---|
| **decide to + 동사원형** | ~하기로 결정하다 (동명사 ✗) |
| **instead of ~** | ~ 대신에 🔄 |
| **rather than ~** | ~보다는 |
| **be left** | 남아 있다 📌 |
| **remain** | 남다 (자동사, 격식) |
| **fighter jet** | 전투기 ✈️ |

### 🔊 an + 모음 "소리" (글자 아님!)

| 표현 | 발음 |
|---|---|
| **an** F-15 | 에프~ ✔️ |
| **an** SU-27 | 에스유~ ✔️ |
| **an** MRI | 엠~ ✔️ |
| **an** hour | 아워~ ⏰ |
| **a** university | 유~ (자음 소리) 🎓 |

> 💡 알파벳 **F, L, M, N, S, X**는 이름이 모음으로 시작! → **an** 🔤

### 📌 be left (남다) 활용

| 표현 | 뜻 |
|---|---|
| One kit **is left**. | 한 개 남았다 |
| How many **are left**? | 몇 개 남았어? |
| Two days **left**! | 이틀 남았다! |
| I have one **left**. | 하나 남았어 |

### 💡 오늘의 팁
- ⚠️ **반복 실수!** yet은 **현재완료**와 짝 — I **haven't finished** it yet ✔️ (8/26에도 틀림)
- **decide + to + 동사원형** 🎯 (decided building ✗)
- **instead of**(~ 대신에) ≠ **more than**(~보다 더) 🔄
- **remain / be left**는 스스로 남는 것 — I remained ✗ 📌
- 🔊 **an**은 글자가 아니라 **소리**로! an F-15, an SU-27 ✈️
- 잘한 점: **an F-15**를 스스로 정확히 사용! 어제 배운 소리 규칙 적용! 👏

## 📝 문법 팁 모음

- **at** + 시각 (at 12:30) / **in** + 기간 (in the morning)
- 목록 마지막엔 **and**: "A, B, **and** C"
- 습관은 현재형: "I **study** English every day" (will 안 씀)
- 원인/결과: **because of** + 명사 / **because** + 문장 / 결과는 **so**
- **ask + 사람 + to + 동사**: "ask you to teach me"
- 장소: **"I'm in [도시]"** (Here is [도시] ✗)
